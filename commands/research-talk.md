# /research-talk — Build a research talk

Use the **research-talk-crafter** skill for this request: $ARGUMENTS

1. From the request, work out the talk type, length, audience and theme. Ask one short question
   only if a wrong guess is costly. Ask whether the user wants speaker notes; if there's no
   answer, write bullet-point notes.
2. Write the one-sentence message and the slide plan (sentence titles, evidence per slide, a "do
   not say" line). Share the titles before building.
3. Build the deck in the chosen theme, in whatever slide format you produce, following the
   skill's rules.
4. Run the skill's review checklist (at most 3 rounds) and report the titles, any placeholders
   left to fill, and any theme devices you changed for the output format.
